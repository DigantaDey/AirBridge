# Code of Conduct

AirBridge is a small project with a simple expectation: be decent to the people
who report bugs, review code and answer questions.

## Expected behaviour

- **Be precise, not personal.** Critique the change, the code or the claim — not
  the person who wrote it.
- **Assume good faith.** Most reports come from someone whose phone behaves
  differently from yours.
- **Stay on topic.** Issue threads are for the issue; take unrelated debates
  elsewhere.
- **Respect privacy.** Never post someone's diagnostics bundle, phone number, IP
  address, screenshot or pairing code without their permission. Redact before
  pasting.
- **Respect the project's boundaries.** Requests to add Accessibility-service
  bypasses, to weaken encryption, to remove consent prompts, or to ship tracking
  will be declined; you are welcome to disagree with the reasoning in a
  discussion, but repeated demands to override the security model are not
  productive.

## Unacceptable behaviour

- Harassment, insults, personal or political attacks, and sustained disruption.
- Discriminatory language or imagery of any kind.
- Sexualised content or attention in any project space.
- Publishing private information without explicit permission.
- Deliberately misleading security or performance claims about this project or a
  competing one.
- Spam, undisclosed promotion, or link-dropping unrelated products.

## Scope

This applies to the repository, issues, pull requests, discussions, and any space
where someone is representing the project.

## Reporting

Report a problem by emailing **hello@airbridge.fyi** with the link or screenshot
and a short description. Reports are read by the maintainer,
[Diganta Dey](https://github.com/DigantaDey), and kept confidential.

Responses will be proportional: usually a clarification or an edit request, and
for repeated or severe behaviour, a temporary or permanent block from the
project's spaces.

## Attribution

This code of conduct is written for this project rather than adapted from a
template; it follows the same expectations as the
