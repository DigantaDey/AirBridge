Explore full technical specifications ＋
Transfer pipeline & integrity

Windowed binary SACK streaming (16 KiB–1 MiB chunks), per-chunk AES-256-GCM AEAD, TCP relay pause/drain backpressure below the 64 MiB cap, 3-strike heartbeat stall checks, incremental SHA-256 + final verification before saving, and loopback daemon retry/resume.

Continuity & native permissions

Contacts persistence tied to connected peer identity + user removal, two-way call audio (`FRAME_CALL_AUDIO` with anti-replay counters), H.264 Annex-B to `avcC` transcoding, and native macOS `NSPasteboard` photo capture. Every phone permission is explicit and optional; zero Accessibility Services.

Cross-platform runtime & CLI

Native Jetpack Compose Android app, ad-hoc signed macOS `AirBridge.app` menu-bar Swift shell, Windows & Linux standalone executables, and `npx airbridge` CLI. One-shot CLI links have different threat properties than E2EE peer transfers; see the README.

04 SECURITY & PRIVACY

Zero accounts.
Encrypted locally.

Your pairing code never leaves your room in plaintext or hashes: AirBridge authenticates peers via SPAKE2 (RFC 9382), derives ephemeral ECDH P-256 shared secrets, encrypts every file chunk, clipboard photo, audio packet, and video frame with AES-256-GCM, and verifies SHA-256 digests before touching your Downloads folder.

Honest platform disclosures: Screen sharing requires explicit approval per session and respects Android DRM (`FLAG_SECURE` content stays blank). Call audio routing uses an opt-in speakerphone-assisted bridge because standard unrooted Android blocks raw cellular uplink injection. Background clipboard never abuses Android Accessibility Services.

01

Install on macOS, Linux, or Windows

macOS & Linux (installs ~/Applications/AirBridge.app or XDG launcher without sudo):

curl -fsSL https://raw.githubusercontent.com/DigantaDey/AirBridge/main/install.sh | bash

Windows PowerShell:

powershell -ExecutionPolicy Bypass -Command "iwr https://raw.githubusercontent.com/DigantaDey/AirBridge/main/install.ps1 -UseBasicParsing | iex"

Prefer running from source? Clone and start locally on port 3000:

git clone https://github.com/DigantaDey/AirBridge.git
cd AirBridge && npm ci && npm run dev
02

Install AirBridge on Android

Open the native Jetpack Compose Android app and scan the QR code displayed on your computer (or pick your Mac from nearby LAN discovery). Every continuity permission — Contacts, Phone Calls, Call Microphone, Screen Capture — stays off until you explicitly toggle that feature on.

06 QUESTIONS

Details that
actually matter.

Clear answers on continuity features, OS constraints, encryption, and troubleshooting.

Ask a question ↗
How smooth is screen sharing from Android to MacBook?＋

Android encodes screen frames via hardware MediaCodec H.264 with cached SPS/PPS codec headers and zero B-frames, while the MacBook client configures ISO 14496-15 avcC WebCodecs decoding, renders synced frames via requestAnimationFrame, and requests instant PLI keyframes if a delta drops. Optional per-session playback audio stays off by default, and DRM-protected apps remain blank by design.

How does MacBook phone-call audio & persistent contacts work?＋

Once you grant Contacts and Phone permissions, contacts synced to your computer stay saved locally until you delete them or disconnect the device. During a call, tapping Use Mac Audio activates an end-to-end encrypted 16 kHz PCM audio bridge between macOS and Android (speakerphone-assisted with Android echo cancellation because unrooted Android restricts raw cellular uplink audio injection).

Will copying a photo on MacBook send gibberish text to Android?＋

No — in v2.5.0 macOS inspects native NSPasteboard image types first instead of piping raw binary pasteboard data through text capture. Copied PNG/TIFF/JPEG images arrive as crisp clipboard images on Android with SHA-256 echo suppression.

Why don’t long file transfers drop mid-stream or near completion anymore?＋

v2.5.0 upgrades the server relay to 3-strike heartbeats that count active TCP bytesWritten progress, throttles saturated sockets before reaching the 64 MiB safety cap, disables short HTTP request timeouts on chunk uploads, retries transient loopback writes, keeps resume identity matched across ephemeral session key refreshes, and re-sends final completion ACKs automatically.

Can I cast Netflix, Hotstar, or DRM-protected streams?＋

No. AirBridge is a consent-based productivity & continuity screen mirror and never bypasses DRM or system flags such as FLAG_SECURE.

Does AirBridge use Accessibility or read my notifications?＋

No. AirBridge does not declare Android Accessibility access or notification-listener access. Use Share → AirBridge, Process Text → AirBridge, the Quick Settings tile, or Paste in AirBridge for reliable clipboard sends from any app.

Why do mobile browsers ask for a local certificate, and does the Android app need it?＋

Mobile browsers require HTTPS for Web Crypto APIs. AirBridge’s built-in local CA uses a fingerprint shown in the Pairing panel and terminal; meanwhile the native Android app pins your paired desktop’s public key directly, so it connects securely without manual OS certificate installs. See the certificate guide for full details.

Does AirBridge use Apple AirDrop?＋

No. AirBridge is an independent open-source project and does not implement proprietary Apple protocols. AirDrop and Continuity are Apple trademarks; AirBridge is not affiliated with Apple or Google.
