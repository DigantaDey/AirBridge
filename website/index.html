01 THE IDEA

The little things
should just flow.

There are already ways to send a file from Android to a Mac. But the little everyday moments—copying a bit of text, sharing a photo, picking up right where you left off—still feel like a detour.

Apple’s Universal Clipboard makes copy on iPhone, paste on Mac feel natural between eligible Apple devices signed into the same account. AirBridge aims to bring that kind of ease to Android and Mac, without pretending the two ecosystems are the same.

Explore everything in the current prototype ＋
Files & transfers

Drag and drop or pick mixed files; preview eligible images in transfer offers; accept, decline, auto-accept trusted peers, or cancel. See speed, ETA and recent history. On the Mac, received files stream to a configurable folder and can be revealed in Finder. Partial files support resuming in supported flows; SHA-256 results are displayed for verification.

Clipboard & devices

Beam text and images, browse the last 50 clipboard items, copy text, open links or save images. Toggle sending and receiving, choose Nearby, Paired only or Hidden visibility, rename devices, and pair with a QR link or code. Browser permissions and device restrictions apply.

More ways to use it

Install the web app as a PWA for Android share-sheet access. Switch themes and sounds, try the clearly labelled demo phone, or use the CLI for a daemon or one-shot file link. CLI links have different security properties from the encrypted app; see the README.

04 GET STARTED

Curious?
Try it today.

Every release ships a one-line macOS installer, an Android APK, and Windows/Linux binaries. You need a Mac and an Android phone on the same Wi-Fi. Building from source needs Node.js 20+, npm and Git.

All downloads Direct APK ↗
Explore the repository ↗
01

Install on your Mac.

Open Terminal and run the installer — no sudo, no accounts, nothing outside your home folder:

curl -fsSL https://raw.githubusercontent.com/DigantaDey/AirBridge/main/install.sh | bash

It installs AirBridge.app in your Applications folder and opens the web interface. Next time, open AirBridge from Launchpad or Finder; no Terminal needed. The local service runs at http://localhost:3000.

Prefer building it yourself?

git clone https://github.com/DigantaDey/AirBridge.git
cd AirBridge
npm ci
npm run dev
02

Get the Android app.

Download AirBridge.apk from the latest release and install it (approve “install unknown apps” once). Updates install straight over the previous version because every release is signed with the same sideload key.

Or skip the app: install the local certificate on your phone by visiting http://<mac-ip>:3000/airbridge-ca.crt, replacing <mac-ip> with the address printed in Terminal. Install it as a CA certificate through Android’s security settings and compare its fingerprint to the one in Terminal.

A CA certificate can affect device trust. Verify the fingerprint and only install a CA you trust. See the full security notes before proceeding.

03

Connect, verify, and share.

Open the printed https://<mac-ip>:3000 address (or the installed app) on your phone. Use Nearby on both devices, or join with the same pair code. Compare the six-digit verification codes, then choose files or share clipboard content.

Keep both ends open while a transfer runs. For a production-style build and more options, see the full setup guide.

05 GOOD TO KNOW

A few things
you might ask.

Something else on your mind? We’re always happy to help.

Say hello ↗
Is the Android app available yet?＋

Yes. Every release includes AirBridge.apk for Android 8.0+ (sideload it — updates install over the previous version) plus a one-line macOS installer. AirBridge is still an open-source prototype, so expect rough edges.

Why do I need to install a certificate?＋

Phone browsers require a secure context for Web Crypto. The local service creates a certificate authority (CA) so your phone can use HTTPS. Verify the fingerprint printed in Terminal against the certificate on your phone. Don’t bypass browser warnings. See the certificate instructions for details and removal.

My phone says “secure connection required.”＋

Make sure you installed the CA certificate and are opening the printed https:// phone address—not the plain HTTP address. On the Mac, http://localhost:3000 is fine.

Why can’t my devices find each other?＋

Check that the service is running, both browsers can reach the same server, and Nearby is enabled on both devices. Try the same pair code on both sides. Guest Wi-Fi, VPNs, firewalls, and client isolation can block connections; try another network or a phone hotspot.

Terminal says Node, npm, or Git is missing.＋

Install Node.js 20 or newer, which includes npm, and Git. Open a new Terminal window and check node -v, npm -v, and git --version. Then repeat the setup commands.

Port 3000 is already in use. What now?＋

Stop the other process, or start AirBridge on a different port with PORT=3001 npm run dev. Use the addresses printed in Terminal and replace 3000 with the chosen port in the steps above.

Where do received files go?＋

On the Mac running the service, the default is ~/Downloads/AirBridge; you can change it in Settings. On the phone, storage behavior depends on browser support: choose a directory when offered, or use the download fallback. Large files may use substantial memory in the fallback.

Will clipboard sharing work in the background?＋

The current Mac service can watch copied text while it runs. On Android, the browser relies on page copy events, the PWA share sheet, or permitted clipboard reads when returning to the tab. Browser and OS restrictions mean fully automatic cross-device clipboard behavior is not guaranteed.

What if a transfer stalls or is interrupted?＋

Keep the Mac service and both browser pages open; backgrounded mobile tabs can be throttled. Try a smaller batch if the phone is using the memory-based download fallback. The Mac keeps partial files for supported resume flows, but an in-flight offer does not recover across a page reload.

Does this use Apple AirDrop?＋

No. AirBridge is an independent project and does not use or implement Apple’s AirDrop protocol. AirDrop and Universal Clipboard are Apple features and trademarks; AirBridge is not affiliated with Apple or Google.
