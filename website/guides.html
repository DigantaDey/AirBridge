AirBridge guides: Android ↔ Mac, Windows and Linux, explained

AirBridge connects an Android phone to a desktop computer without an account, a cloud drive or a proprietary protocol. These guides explain how each capability works, what it needs on your machine, and where the honest limits are.

Each guide below explains the problem it solves, what AirBridge actually does on that platform, how the encryption and permissions work, and where another tool may be the better choice. Start with the platform you use today:

  • Android to Mac file transferWi-Fi file transfer from Android to macOS with resume, SHA-256 checks and no cloud upload.
  • Android to Windows file transferPortable Windows app, no admin rights, encrypted Wi-Fi transfers from Android.
  • Android to Linux file transferNo root, XDG launcher entry, static glibc/musl builds for x64 and arm64.
  • Android AirDrop alternativeWhat an AirDrop replacement for Android actually needs, and where AirBridge fits.
  • Android clipboard syncText both ways, photos on macOS — without Accessibility access.
  • Android screen sharingConsent-based H.264 viewing of your phone on a Mac, Windows or Linux desktop.
  • Open-source AirDrop alternativeAuditable code, a self-hostable relay and an honest note about the licence.
  • Private file transferNo account, no cloud copy — and an honest list of what can still be observed.

Which guide should I read?

  • Just moved files from Android to a computer: the Android to macOS, Windows or Linux guide.
  • Trying to replace AirDrop: the Android AirDrop alternative guide, plus the open-source alternative guide if licensing matters to you.
  • Copy and paste between phone and computer: the Android clipboard sync guide.
  • Showing your phone screen on a computer: the Android screen sharing guide.
  • Evaluating the privacy model: the private file transfer guide, then the project's own security notes.
